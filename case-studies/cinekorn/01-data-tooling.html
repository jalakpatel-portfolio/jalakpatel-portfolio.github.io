Case 01 · Data and tooling

Data bottleneck and AI-assisted tooling

Using an AI-assisted Python workflow to classify 6,000 to 8,000 rows so catalogue distribution could run with structure instead of spreadsheet drag.

Context

Volume blocked the operating rhythm

Catalogue work depends on knowing what each title is, which language and format it fits, and whether it is ready to publish. When thousands of rows sit unclassified, every distribution decision slows down.

Problem

Manual classification could not keep up

Hand-tagging 6,000 to 8,000 rows was not a realistic path to a usable operating sheet. The bottleneck was structure, not effort alone.

Strategy

AI assist with human checks

A Colab workflow used model assistance to propose classifications, then human review locked decisions. Speed without surrendering judgment.

Evidence

Workflow surface

Takeaway

Speed without giving up judgment

The goal was not full automation. It was a defensible way to move thousands of rows into a structure the distribution work could use.
